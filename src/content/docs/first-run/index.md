Your first ten minutes follow the order the app walks you through. You open the token link and are signed in. A fresh install then sends you to the welcome wizard. There you pick a model provider, Timothy checks that it answers, and it shows which model does which job. You pick a first message and Timothy answers it in Chat. Back on Home, a setup checklist tracks what is left, and it can start a sample mission for you. Each main page shows a short tour on your first visit. The Help menu in the top bar brings back the checklist, a page's tour, the welcome wizard and these docs.
