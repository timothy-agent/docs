You talk to an agent in a chat. An agent is a named assistant with its own instructions and tools. Its model comes from a route, and a route picks from the providers you connected. Some work takes longer than one answer. That work becomes a mission, which Timothy plans, does and checks by itself. Memory and knowledge feed both chats and missions. Memory holds facts Timothy learned from you. Knowledge holds documents you gave it. Automations start missions on a schedule or when something happens. Connectors let Timothy reach your accounts, and channels let you reach Timothy from apps like Telegram.

- [Agents](/docs/concepts/agents/): who answers a chat, with which instructions and tools.
- [Providers and routes](/docs/concepts/providers-and-routes/): where models come from and which model does which job.
- [Missions](/docs/concepts/missions/): longer tasks Timothy works on by itself.
- [Memory](/docs/concepts/memory/): facts Timothy remembers between chats.
- [Knowledge](/docs/concepts/knowledge/): documents Timothy can search and quote.
- [Automations](/docs/concepts/automations/): missions that start on a schedule or an event.
- [Channels and connectors](/docs/concepts/channels-and-connectors/): how Timothy links to outside services.
